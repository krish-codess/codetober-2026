# Data dictionary

Generated by `bakeoff docs` from `bakeoff/taxi.toml`. Do not edit by hand.

## `nyc_yellow_taxi`

NYC TLC yellow-taxi trip records, one row per metered trip.
Every variant holds these columns, sorted by `pickup_datetime`.

| Column | Source header | Type | Nullable | Unit | Meaning |
|---|---|---|---|---|---|
| `vendor_id` | `VendorID` | INTEGER | no | code | TPEP provider that produced the record: 1 Creative Mobile, 2 Curb, 6 Myle, 7 Helix. |
| `pickup_datetime` | `tpep_pickup_datetime` | TIMESTAMP | no | local time, s | Meter engaged. Sort key of every variant. |
| `dropoff_datetime` | `tpep_dropoff_datetime` | TIMESTAMP | no | local time, s | Meter disengaged. |
| `passenger_count` | `passenger_count` | BIGINT | yes | people | Driver-entered. NULL on the 5-8% of rows that arrive without trip metadata. |
| `trip_distance` | `trip_distance` | DOUBLE | no | miles | Taximeter distance. |
| `ratecode_id` | `RatecodeID` | BIGINT | yes | code | Final rate code: 1 standard, 2 JFK, 3 Newark, 4 Nassau/Westchester, 5 negotiated, 6 group, 99 unknown. |
| `store_and_fwd_flag` | `store_and_fwd_flag` | VARCHAR | yes | Y/N | Y when the record was held in vehicle memory before upload. |
| `pu_location_id` | `PULocationID` | INTEGER | no | TLC zone 1-265 | Pickup taxi zone. |
| `do_location_id` | `DOLocationID` | INTEGER | no | TLC zone 1-265 | Dropoff taxi zone. |
| `payment_type` | `payment_type` | BIGINT | no | code | 0 flex fare/unknown, 1 card, 2 cash, 3 no charge, 4 dispute. |
| `fare_amount` | `fare_amount` | DOUBLE | no | USD | Time-and-distance fare. Negative on voids and adjustments. |
| `extra` | `extra` | DOUBLE | no | USD | Rush-hour and overnight surcharges. |
| `mta_tax` | `mta_tax` | DOUBLE | no | USD | MTA tax triggered by the metered rate. |
| `tip_amount` | `tip_amount` | DOUBLE | no | USD | Card tips only; cash tips are not recorded. |
| `tolls_amount` | `tolls_amount` | DOUBLE | no | USD | Tolls paid in trip. |
| `improvement_surcharge` | `improvement_surcharge` | DOUBLE | no | USD | Flat surcharge at flag drop. |
| `total_amount` | `total_amount` | DOUBLE | no | USD | Charged to the passenger, excluding cash tips. |
| `congestion_surcharge` | `congestion_surcharge` | DOUBLE | yes | USD | NYS congestion surcharge. |
| `airport_fee` | `Airport_fee` | DOUBLE | yes | USD | Pickup fee at LaGuardia and JFK. |

## Validation rules

A quarantined row goes to `quarantine/rejects.parquet` with its reason. A counted row is kept and tallied in `clean/ingest.json`.

| Rule | Action | Condition | Why |
|---|---|---|---|
| `unparseable` | quarantine | the CSV line does not parse to the column types | Wrong field count, text in a numeric column, a non-ISO timestamp. |
| `null_in_required` | quarantine | NULL in a non-nullable column | The contract above. |
| `duplicate` | quarantine extra copies | row identical to another in all columns | An upstream replay. |
| `pickup_far_outside_file_month` | quarantine | `date_diff('month', strptime(source_month, '%Y-%m'), pickup_datetime) NOT BETWEEN -1 AND 1` | Each monthly file carries a handful of trips stamped 2002, 2008 or 2009: meter clock faults, not late data. |
| `dropoff_before_pickup` | quarantine | `dropoff_datetime < pickup_datetime` | A trip cannot end before it starts; durations and any time-based rate are meaningless. |
| `trip_distance_implausible` | quarantine | `trip_distance < 0 OR trip_distance > 500` | The real feed contains trips of 300,000 miles. One such row moves the column mean by 10%. |
| `location_out_of_range` | quarantine | `pu_location_id NOT BETWEEN 1 AND 265 OR do_location_id NOT BETWEEN 1 AND 265` | Zone ids outside the TLC zone table break every join to zone geography. |
| `late_arrival` | count | `date_diff('month', strptime(source_month, '%Y-%m'), pickup_datetime) <> 0` | Trips from the adjacent month that arrived in this file. Valid, kept, and sorted into place. |
| `negative_amount` | count | `fare_amount < 0 OR total_amount < 0` | Voids and adjustments (~1.4% of rows). Real records: dropping them silently would change every revenue sum. |
| `unknown_vendor` | count | `vendor_id NOT IN (1, 2, 6, 7)` | Provider code missing from the TLC data dictionary. |
| `zero_passengers` | count | `passenger_count = 0` | Driver-entered field left at zero. |
| `trip_over_24h` | count | `dropoff_datetime - pickup_datetime > INTERVAL 24 HOUR` | Meter left running. Kept; flagged for anything computing durations. |

## `quarantine/rejects.parquet`

| Column | Type | Nullable | Meaning |
|---|---|---|---|
| `reason` | VARCHAR | no | Rule id, `duplicate`, or `unparseable`. |

## `results/measurements.parquet`

One row per benchmark execution.

| Column | Type | Nullable | Unit | Meaning |
|---|---|---|---|---|
| `seq` | BIGINT | no | | Stable order of executions; the pagination cursor. |
| `variant` | VARCHAR | no | | Variant id, e.g. `parquet-zstd3-rg100k`. |
| `query` | VARCHAR | no | | Query id from the workload. |
| `kind` | VARCHAR | no | | `cold`, `warm`, `counted` or `error`. |
| `ts` | VARCHAR | no | UTC ISO-8601 | When the execution finished. |
| `seconds` | DOUBLE | yes | s | Wall time. NULL for `counted` and `error`. |
| `cpu_s` | DOUBLE | yes | s | Process CPU time, all threads. |
| `bytes_read` | BIGINT | yes | bytes | Bytes the reader pulled from storage; `counted` only. |
| `reads` | BIGINT | yes | calls | Read calls made to storage; `counted` only. |
| `ok` | BOOLEAN | yes | | Result matched the answer from `clean/source.parquet`. |
| `error` | VARCHAR | yes | | Exception text; `error` only. |
